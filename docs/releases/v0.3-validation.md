## Commands and results

The complete public route is:

```sh
PYTHON=.venv/bin/python ./tests/run.sh all
```

It rebuilds the public simulator and runs NNC unit discovery, all discovered
model smokes plus Llama profiling, packed C++ tests, interface tests and all
nine original independent examples. Before adding the native wrapper examples,
the command completed with exit status 0:

| Check | Result |
| --- | --- |
| NNC Python unit discovery | PASS, 43 tests |
| Freshly generated model harness, including Llama profile | PASS, 56/56 cases |
| Packed WSLD C++ regression | PASS, 26/26 configurations and simulator `TEST PASS` |
| Typed/generic weight-pack C++ regression | PASS, 16/16 configurations and simulator `TEST PASS` |
| Public interface | PASS, 3 filelist unit tests, 6/6 matmul cases and simulator `TEST PASS` |
| Independent saved/source examples | PASS, 9/9: hello, tensor, ACTU, scalar FP4, scalar FP8/BF16, Linear FP4, Q8_0 and both FP8 formats |

The extra strict checks reuse the freshly built simulator. Run all 29
unbiased fixtures (27 original plus two native wrapper examples) from the
workspace root with Bash:

```sh
for model in nnc/test/smoke_linear_{fp4,mxfp4,nvfp4,q8_0}*.py; do
  case "$model" in
    */smoke_linear_fp4_example.py|*/smoke_linear_q8_0.py) continue ;;
  esac
  extra=()
  if [[ "$model" == */smoke_linear_q8_0_typed.py ]]; then
    extra=(--main-file src/edge-nnc/nnc/test/q8_0_typed_main.cpp)
  fi
  PYTHON=.venv/bin/python ./scripts/run-nnc.sh smoke \
    --model-file "$model" "${extra[@]}" \
    --skip-verilator-build --max-abs-error 0 || exit 1
done
PYTHON=.venv/bin/python ./example/linear_q8_0/run.sh \
  --skip-verilator-build --max-abs-error 0.001953125
```

Strict audit: 27 unbiased FP4/MXFP4/NVFP4/Q8_0 cases PASS with zero
tolerance; the biased Q8_0 model PASS with `2^-9` absolute tolerance.
An additional zero-tolerance probe of the biased FP4 example FAILS with
BF16 bias-add rounding differences (maximum absolute error `2^-9`). Its
ordinary harness run passes. Neither biased example is claimed to be bit
identical to PyTorch addition. The ordinary harness defaults to absolute
tolerance `0.05`; its PASS alone cannot prove the tiny-contribution claim.

Local raw logs are under ignored `build/release-v0.3-audit/`; ordinary suite
summaries are under `build/tests/all/`, NNC's `example/llama/build/harness/`
and `tests/nnc/build/packed/`. Generated logs and build products are not
release source artifacts.

## Issues found and fixed

- The saved Q8_0 weight payload still contained BF16 scales while the updated
  runtime expected FP16. It produced 144/144 incorrect outputs. Regenerated
  `weight.bin` and `expected.bin` from the public source model; the saved
  example then passed its 144-value comparison with maximum error `2^-9`.
- Corrected stale Q8_0 scale descriptions and the assertion that byte-scale
  support was reserved. Distinguished the BF16-scaled intrinsic tutorial
  from the native FP16-scaled named Q8_0 preset.
- Corrected the description of saved-artifact runners versus regeneration,
  and replaced an obsolete SDK `example/tensor_formats` link.
- Made the hello example exercise writable `.data` explicitly.
- Replaced the unaudited n906 / maintainer regression statement with this
  public evidence map.

## Scope limits

This is E3 RTL simulation and source inspection. E4, silicon, physical
timing and model-quality results are excluded. Direct-intrinsic cycle and
utilization measurements are recorded separately in the performance snapshot.
Private exhaustive leaf tests, including FP16 loader sweeps mentioned in
NNC documentation, are not counted as public hardware evidence here.
The public unit tests' FP16 bit-pattern checks concern software encoding;
hardware coverage here comes from the public end-to-end fixtures.
