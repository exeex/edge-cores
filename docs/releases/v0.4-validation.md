## JTAG example

The example now compiles only public Edge32 RTL and its versioned local RAM,
remote_bitbang server, OpenOCD configuration and console client. No test-32,
prepared views, gate netlists, external physical-workspace files or existing
simulator binaries are used. `EDGE32_DEBUG` selects the native controller,
scalar architectural debug state, GPR access and cache maintenance. The default
non-debug ports/configuration are retained. FPU is disabled and MISA is RV32IM.

```sh
git submodule update --init src/edge-32
./examples/jtag-hello/run.sh
```

Tools: Verilator 5.050, OpenOCD 0.12.0, RISC-V GDB 18.1, LLVM clang/LLD and
VS Code Microsoft C/C++ 1.35.6 on macOS ARM64.

PASS: pin-level TAP IDCODE/DTMCS/BYPASS; DMI errors and hart selection; empty-RAM
ELF download via SBA; byte/halfword/word memory access and errors; GPR writes;
single-step/resume acknowledgement; exact-PC raw breakpoint; previously cached
instruction patching; dirty-cache reads and partial writes; automatic halt/resume
for running SBA; console FIFO and overflow; TAP reset, ndmreset and external SRST.
Real OpenOCD register/step and console client checks also passed.

PASS: cppdbg DAP launch, stop at main, source breakpoint, stack trace, Watch,
disassembly, source step, completion with `characters_written == 25`, exact JTAG
greeting, disconnect, owned-process cleanup, released ports/control socket,
repeated stop and fresh start/stop. Source hashes are in `sim/inputs.json`.

The actual VS Code GUI was additionally exercised in the edge-cores workspace:
Start Debugging ran the build and server tasks and stopped at `main`; a gutter
breakpoint on main.c:11 was hit; Step Over and Step Into worked (the latter
showed `ch == 72` in `edge_putchar`); Watch reached `characters_written == 25`;
the terminal printed the complete greeting; Stop ran `postDebugTask`; and a
fresh launch/stop succeeded. GUI navigation briefly inserted text in main.c;
it was fully restored, and a subsequent GUI launch rebuilt the original ELF.
The final source has no diff.

Local evidence is under `build/jtag-hello/`: `public-test.log`, `test.report`,
`dap-check.log`, `session.log`, `restart.log`, `sim/build.log`, and
`sim/inputs.json`. FPU state, physical-board JTAG, standard GDB hardware
breakpoints and physical JTAG timing remain outside coverage.
