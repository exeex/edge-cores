## Compatibility checks and repairs

Before regeneration, all six v0.3 saved Linear artifact sets passed against
the new NNC runtime. Each compared 144 outputs; MXFP4 and NVFP4 had zero
absolute error, while biased FP4/Q8_0/FP8 examples had maximum absolute error
`2^-9`, within their existing runner tolerance. Logs are
`build/release-v0.3.1/saved-before-<format>.log`.
The six examples were then regenerated with the release compiler, preserving
weights and logical goldens while updating physical I/O order and including
`io_layout.json`. Decoding each regenerated input/golden with its recorded
layout reproduces the old bytes exactly; all six packed weight payloads are
unchanged. Final saved replay is covered by the complete suite.

The first integration run exposed the following issues, repaired before the
final suite:

- Restored missing MXFP4/NVFP4 source models, mains and smoke links in NNC.
- Restored NNC's editable build backend and corrected invalid `edge-nnc`
  extra markers in its lockfile without changing locked dependency versions.
- Linked NNC's weak freestanding `memcpy` support into workspace C++ builds;
  the original weight-pack regression otherwise failed to link.
- Updated the direct Matmul sentinel's fixture storage for the tiled runtime
  ABI and published output guards before DMA. Its independent integer
  goldens, six shapes and bit-exact checks are retained.
- Added opt-in public simulator MAC/command evidence and recognized its
  existing success marker in the quant benchmark. Numerical tolerances and
  MAC/START/DMA assertions are unchanged.
- Added the existing NNC cache ownership C++ fixture to the workspace adapter.

The first run's NNC model portion passed 59/59 discovered cases before the
two restored wrapper smoke links were rediscovered by the final suite.
Its overall failure due to the missing metadata-copy linker support is not
counted as a passing full regression. The corrected interface separately
passed all six cases with simulator `TEST PASS`.
